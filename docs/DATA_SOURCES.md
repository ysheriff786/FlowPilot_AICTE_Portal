# Data sources

Values that must come from an external authority and who enters them:
- Routing rules (category x isNew -> route): AICTE Approval Process Handbook. Entered by admin on /routing.
- Document requirement lists per category/year: AICTE Approval Process Handbook. Entered by admin on /requirements.
- State-to-region mapping: official government mapping. Entered by admin on /routing.
- SMTP provider credentials: IT team.
